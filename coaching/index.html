[01] the method

Every session ends with something that works.

Not a list of tools. We take how you work today, decide what AI should do, and build it together, live.

  1. Map.

    Write down how you actually work, step by step: research, critique, specs, copy, handoff, your portfolio.

  2. Redesign.

    Mark what AI should do, what it should speed up, and what stays human: taste, judgment, relationships.

  3. Build.

    Make the prompts, agents and tools for the new workflow, then use them on your real work.

[06] questions

Do I need to know how to code?

No. Most of what we build is done by describing what you want in plain words. If you can explain a design decision, you can do this.

Which tools do we use?

Whatever fits the job. The focus is the skill underneath, like writing a clear prompt, building an agent, chaining steps and putting something online, so it carries over when the tools change.

Yes. We set one goal in week one so there’s something to finish, but if something more important comes up, we follow it.
