How I built this

I designed and built the new scott-dickie.com by talking to Claude Code: one prompt at a time, checking each change in the browser, then shipping it. Here are the prompts, the ideas behind them and every update along the way.

Process & tools

I described what I wanted in plain words, Claude Code wrote the code and checked it in a browser, and I reacted to what I saw. When a change looked right, it was committed and pushed live. These are the tools I used along the way.

  • Claude CodeIn the Claude desktop app: writing the code, checking it in a browser and committing
  • Plain HTML, CSS and JavaScriptNo framework and no build step, so every page is one file you can read
  • CanvasThe ASCII portrait, the record’s wave and Play’s star field
  • GitHub and VercelEach push to main deploys on its own
  • Claude APIBehind LOC-1’s scene finder
  • Suno, eMastered and FL StudioFor the songs on the record player

The brief

The old site was a straightforward portfolio. I wanted the homepage to show how I actually work now: hands on, curious and making things with AI. This is the prompt that started the redesign.

…using the ascii portraits, 3d interactions, create a new website design with the current content on the work side, but add a new toggle with a “Play” option that will change the visual design (make the colors more colorful while keeping the branding similar)The kickoff prompt, Nov 5

One identity, two audiences. Work is for the people hiring me. Play is for everything I make after hours. Same face, same type and grid, different mood.

The portrait is the brand

Instead of a logo, the identity comes from my face drawn in characters: monospaced type, flannel navy ink and beard ginger for anything you disturb. It reacts to your cursor, your camera and a shake.

Work by day, Play by night

One page, two moods. Work is the daylight version for hiring managers. Play is the same type and grid at night, with more color, a star field and livelier motion for side projects.

  3. Nov 55 commits

    The new homepage

    The kickoff prompt became an ASCII portrait with a Work / Play switch. Then came the craft: the face had to read clearly and keep up with you.

    make the ascii design more detailed, it’s hard to see the details of the eyes on the light background

    Name the exact problem. On the light Work background the face washed out. Pointing at the eyes led to a finer grid and to each character being pushed lighter or darker against its neighbors, so the glasses, eyes and smile read clearly.

    improve the performance of the ascii interactions so it keeps up with the cursor and video

    Feel is part of the design. Claude timed the portrait frame by frame and found that drawing cost jumps sharply below 3.2px per character. Settling the grid there made the face about 3.5× faster while keeping nearly all of the detail.

    • ASCII portrait with Work and Play modes
    • Faster drawing and darker characters for Work
    • A sharper, wider Get Unstuck screenshot

  4. Nov 625 commits
